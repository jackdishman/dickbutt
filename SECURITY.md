# Security Policy

This project handles on-chain token custody and rewards distribution. If you find a security vulnerability, please report it privately rather than opening a public issue.

## Reporting a vulnerability

- Preferred: use [GitHub's private vulnerability reporting](../../security/advisories/new) for this repository.
- Alternative: email me@jackdishman.com with details and, if possible, steps to reproduce.

Please do not disclose the issue publicly (including in GitHub issues or PRs) until it has been addressed.

## Scope

This covers the smart contracts in `src/`, the off-chain calculator/keeper/operations tooling, and deployment scripts in this repository. See [AUDITOR-BRIEF.md](AUDITOR-BRIEF.md) for known open items and unverified assumptions.
